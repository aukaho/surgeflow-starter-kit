SurgeFlow API Beginner Quickstart

Status: free public API beta.

Create a key:
https://surgeflows.capital/membership#api-key

1. Enter your email and optional name.
2. Agree to the terms.
3. Click Create key.
4. Copy the key when it appears. It starts with sf_live_.
5. Use the website preview or Colab notebook to load a current-session
   turnover table or momentum hotlist.

The full key is displayed once. Keep it private.

Current API offer

- 13 authenticated, read-only endpoint families
- Four markets: us, cn, jp, hk
- 2,000 requests per day per key
- 180 requests per minute per key
- Market, ML, whale, sector, news, factor, Notes, macro, and bond research
- The AI research committee is paused; /api/v1/ai/ratings and
  /api/v1/ai/grade-book are retired (HTTP 410)

cURL example:

export SURGEFLOW_API_KEY="sf_live_..."

curl -H "Authorization: Bearer ${SURGEFLOW_API_KEY}" \
  "https://stock-api-c4qdowjxva-uc.a.run.app/api/v1/me"

curl -H "Authorization: Bearer ${SURGEFLOW_API_KEY}" \
  "https://stock-api-c4qdowjxva-uc.a.run.app/api/v1/markets/us/realtime?limit=25"

Python example (set the SURGEFLOW_API_KEY environment variable first; never
paste the key into your code):

import os

import requests

base_url = "https://stock-api-c4qdowjxva-uc.a.run.app"
api_key = os.environ["SURGEFLOW_API_KEY"]
headers = {"Authorization": f"Bearer {api_key}"}

response = requests.get(
    f"{base_url}/api/v1/markets/us/hotlist",
    headers=headers,
    timeout=30,
)
response.raise_for_status()
rows = response.json()["data"]["rows"]
print(rows[:5])  # an empty list is normal: a hotlist often has no names

Data boundary

The endpoint name realtime describes a current-session board. SurgeFlow does
not claim a live-tick feed across all four markets. Historical, factor, and
fundamental outputs may be current to the last completed market session.
Inspect freshness and evidence fields before use.

SurgeFlow is research software. It does not place orders and is not investment
advice.
