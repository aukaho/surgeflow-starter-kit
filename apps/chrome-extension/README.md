# SurgeFlow Chrome extension

This Manifest V3 popup reads no-key public SurgeFlow snapshots without sign-in.
It is not yet in the Chrome Web Store.

The extension has no permissions, host permissions, content scripts, background worker, build step, or remote code.

## Load unpacked

1. Open `chrome://extensions` in Chrome.
2. Turn on **Developer mode**.
3. Select **Load unpacked**.
4. Select this `apps/chrome-extension` directory.
5. Select the SurgeFlow toolbar button to open the popup.

Select the United States, China, Japan, or Hong Kong.
Read the Hotlist tickers and SurgeFlow ranks, data freshness, and macro statistics with publisher credits.

The extension shows only SurgeFlow tickers and SurgeFlow ranks, data freshness, and official open-licence macro statistics with credits. These official statistics can include economies beyond the four equity markets (for example the United Kingdom, Taiwan, and World Bank country series), each with its publisher credit.
It shows no prices, returns, or company names.
The popup clears all data if any snapshot request or parse fails.

Research data only, not investment advice. Market data can be delayed.
