SurgeFlow Starter Kit

This folder is the website-hosted starter kit for the free SurgeFlow API and Google Sheets beta.

Files:

- surgeflow-google-sheets-starter.xlsx: starter workbook users can upload to Google Sheets or inspect locally.
- surgeflow-api-quickstart.txt: compact API quickstart for beta users.
- surgeflow-realtime-hotlist-60s.ipynb: beginner Jupyter notebook for realtime and hotlist tables with 60-second refresh.
- surgeflow-starter-kit.zip: portable package for users or a future GitHub release.

The ZIP includes the Apps Script appsscript.json manifest with narrow Google
Sheets scopes, plus Code.gs and Sidebar.html.

Release base URL:

https://stock-api-c4qdowjxva-uc.a.run.app

Create a free beta key from:

https://surgeflows.capital/extension

The form asks only for name, email, and terms agreement. The key appears once.

Use the direct Cloud Run API base URL for external scripts, notebooks, and third-party browser apps. The surgeflows.capital API proxy is for same-origin SurgeFlow website pages.
